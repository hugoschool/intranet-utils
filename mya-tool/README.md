# mya-tool

Tool to interact with [MYA](https://mya.epitech.eu/)

## Usage

```sh
uv run main.py
```

## Commands

All commands & subcommand should have a `--help`.

- `download`: Download the entire program as JSON
- `destinations`: Destination related subcommands
  - `country`: List all countries available
  - `school`: List all schools in a CSV format
